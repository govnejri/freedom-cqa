# Проверка всего функционала

Проходи сверху вниз. У каждого пункта отметь `[x]`, если работает как описано. Замечания пиши в строке «→» под пунктом — что сломано, что непонятно, что некрасиво. Отдельно ценны замечания по UX: «не понял, куда нажать», «много шагов», «главное не видно». Когда закончишь, скажи «готово»: я прочитаю файл и исправлю всё по списку.

## 0. Запуск на копии базы

Копия нужна, чтобы апелляции, версии чек-листа и тренировки при проверке не попали в данные для демо.

```bash
cp var/cqa.db var/check.db
DB_PATH=var/check.db uv run cqa serve --port 8000
```

Открой http://127.0.0.1:8000. Если сервер уже был запущен, перезапусти его, чтобы подхватить последние исправления.

Платные действия (вызывают Gemini) помечены **$**. Каждое стоит центы; вся проверка — меньше $1.

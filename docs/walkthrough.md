## 0. Запуск на копии базы

Копия нужна, чтобы апелляции, версии чек-листа и тренировки при проверке не попали в данные для демо.

```bash
cp var/cqa.db var/check.db
DB_PATH=var/check.db uv run cqa serve --port 8000
```

Открой http://127.0.0.1:8000.

Платные действия (вызывают Gemini) помечены **$**. Каждое стоит центы; вся проверка — меньше $1.
